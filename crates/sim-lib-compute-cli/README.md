# sim-lib-compute-cli

`sim-lib-compute-cli` exports the loadable `cli/main/compute` command surface.
It inspects installed compute sites, renders bounded probe and profile evidence,
accepts profile storage only as a caller-supplied Table or Dir value, and
captures or verifies the sanitized portable physical acceptance artifacts. A
capture names one registered target capability with `--target`; the verifier
binds NVIDIA RTX 5080 Laptop, NVIDIA RTX 5090, and AMD gfx1151 artifacts to
their matching physical adapter identities. The committed portable-v1 evidence
set records verifier-clean wgpu captures for all three targets against
`504255b534e69a37d7163ba06048bc23ebdb7cb4`.
